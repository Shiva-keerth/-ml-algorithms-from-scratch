# Machine Learning & AI Algorithms from Scratch 🧠

Welcome to my **Machine Learning from Scratch** portfolio repository! This project is a comprehensive deep dive into the mathematical foundations and code implementations of modern Machine Learning, Deep Learning, Natural Language Processing (NLP), and Computer Vision algorithms.

Instead of just using standard libraries like `scikit-learn`, I built these algorithms from the ground up to deeply understand the underlying mathematics (Linear Algebra, Calculus, and Probability).

## 🚀 Key Implementations

### 1. Traditional Machine Learning
*   **Linear & Multiple Regression**: Predicting continuous values (e.g., housing prices).
*   **Decision Trees & Random Forests**: Implementing node splitting, Gini impurity, and ensemble bagging.
*   **K-Nearest Neighbors (KNN)**: Custom distance metrics for classification.
*   **K-Means Clustering**: Unsupervised learning for customer segmentation (Mall Customers dataset).

### 2. Deep Learning & Neural Networks
*   **TensorFlow & Keras Pipelines**: Building forward propagation, backpropagation, and loss functions.
*   **Computer Vision (MediaPipe)**: Hand tracking and AI-powered interaction tools.

### 3. Natural Language Processing (NLP)
*   **Sentiment Analysis**: Built custom Bag-of-Words and N-Gram models from scratch, alongside Vader Sentiment implementations.
*   **Cosine Similarity Engines**: Built text matching and recommendation engines purely using mathematical vectorization.
*   **LLM Integration**: Chatbot pipelines utilizing Groq and Gemini API endpoints.

## 🛠️ Tech Stack
*   **Language**: Python 3.12
*   **Libraries**: NumPy, Pandas, TensorFlow, OpenCV, MediaPipe, NLTK
*   **Interactive UI**: Streamlit (Used to build front-end interfaces for the algorithms)

## 📂 Project Structure
Each folder represents a specific algorithm or concept and contains:
1.  The raw `.py` implementation from scratch.
2.  The `Streamlit` front-end visualization code.
3.  The `.csv` datasets used for training and evaluation.
